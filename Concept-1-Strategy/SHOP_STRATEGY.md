# Shop Page Strategy - DreamPlay Pianos

## High-Level Vision
Transform the existing "Harmony Sound" template into the primary conversion destination for `shop.dreamplaypianos.com`.

## Layout Requirements
1. **Dynamic Storefront**: Needs to feel like a high-end, seamless "Shop" experience. 
2. **Pathing**: The primary landing spot for all CTAs from the main informational site.
3. **Reference Design**: Mirror the Shopify "Concept" theme demo (seamless mobile experience, carousel swipes, popup closings).

## Content Mapping
- **Hero**: Use `keyboard_hero.jpg` or `keyboard_studio.avif`. Headline: "The Pro Keyboard for Hands That Don't Fit the Standard."
- **Social Proof**: Lionel Yu Carnegie Hall shot (`lionel_performance.png`) and Dr. Carol Leone testimonial.
- **Biometric Selection**: Use the hand span diagrams (`hand_zone_a`, `hand_zone_b`, `hand_zone_c`) to guide size selection (DS5.5 vs DS6.0).
- **Product Options**: Midnight Black vs Pearl White finishes. 

## Conversion Optimization
- Seamless mobile first UI.
- Direct "Reserve Now" CTAs that path to logical checkout/deposit steps.
- Clear biomechanical "Why" explained through saved diagrams (`hand_strain.png` vs `hand_relaxed.jpg`).
